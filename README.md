# Голосования на Jetpack Compose

Приложение для последовательного голосования с одного устройства. Два ответа на каждый вопрос. Данные хранятся в памяти.

## Как пользоваться

1. Создать вопрос и два непустых ответа.
2. Открыть активное голосование, выбрать ответ и нажать «Проголосовать».
3. После сообщения «Голос учтён» нажать «Следующий участник». Выбор сбрасывается, голоса сохраняются.
4. Завершить голосование через диалог подтверждения. Отмена позволяет продолжить.
5. Посмотреть результаты: голоса или проценты, полосы и сортировка по популярности.

До завершения статистика скрыта. Завершённое голосование нельзя открыть для новых голосов. В списке есть фильтры «Все / Активные / Завершённые».

## Где находится код

| Файл | Что объяснять |
|---|---|
| `Poll.kt` | Данные и три действия: `vote`, `nextParticipant`, `finish` |
| `MainActivity.kt` | Общий список, обработчики и выбор экрана через `when` |
| `PollListScreen.kt` | Карточки, статусы и фильтр |
| `CreatePollScreen.kt` | Три поля и проверка ввода; форма осталась прежней |
| `PollDetailsScreen.kt` | Выбор ответа, подтверждение голоса, следующий участник и диалог завершения |
| `PollResultsScreen.kt` | Итоги, проценты, полосы и сортировка |

## Главное для защиты

`isFinished` означает, что голосование завершено. `hasVoted` означает, что текущий участник уже проголосовал. Эти значения хранятся вместе с голосованием, поэтому возврат к списку не позволяет учесть голос повторно.

`vote` проверяет оба признака перед изменением счётчика. Повторный вызов ничего не меняет. `nextParticipant` снимает отметку `hasVoted`, сохраняя счётчики. `finish` устанавливает `isFinished`; обратного действия нет.

Все поля `Poll` объявлены через `val`. Действия возвращают новую копию через `copy`. `PollApp` заменяет элемент наблюдаемого списка, и Compose обновляет экран. Обработчики читают текущий элемент списка, поэтому быстрые повторные нажатия не добавляют второй голос.

Номер нового опроса равен `polls.size + 1`. Это подходит, потому что опросы только добавляются и не удаляются.

`remember` сохраняет состояние между обновлениями интерфейса. `PollFilter` — три возможных значения фильтра. Проценты считаются из тех же счётчиков; при нуле голосов результат равен нулю.

Распределение для объяснения: один участник — список, модель и `MainActivity`; второй — создание, голосование и результаты. Оба должны понимать весь сценарий.

## Запуск

Открыть корень проекта в Android Studio. Gradle JDK 21, Android SDK 36. Дождаться Sync и запустить `app` на эмуляторе.

Сервер и база данных не используются. Данные сохраняются при переходах между экранами. Завершение процесса или пересоздание Activity очищает их.
